# CAPTCHA Verification Task 🔐

This is a simple web-based CAPTCHA verification project built using **HTML**, **CSS**, and **JavaScript**. It generates a random alphanumeric CAPTCHA code that users must enter correctly to validate they are not a bot.

---

## 🚀 Features

- Random CAPTCHA code generation
- Client-side validation using JavaScript
- "Reload CAPTCHA" functionality
- Basic UI styling for a clean user experience
- Real-time error messages for incorrect entries

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the page
- **CSS3** – Styling and layout
- **JavaScript** – CAPTCHA logic and interactivity
